Set **Invoice Name** on the *Sales* tab of the product. Customer invoice and
credit note lines for that product are then labelled with it; the *Quotation
Description*, when set, still follows on the line below, as it does for the
product name. A product with no invoice name is labelled as before.

The label is replaced only while it is the one the product would give. A label
typed by hand on a line is kept, and so is a label carried over from a sales
order line, since the order line is what the invoice line is created from.
Vendor bills are not affected.
