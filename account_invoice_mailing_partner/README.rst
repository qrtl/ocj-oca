In some businesses the printed invoice has to be sent to a contact that
is not the billing partner: a head office that collects the invoices of
its branches, an outsourced accounting firm, or a specific department of
the customer.

This module separates the *billing partner* from the *invoice mailing
address*. The invoice is still issued to, and accounted for, the billing
partner; only the recipient address printed on the document is replaced.

It adds an **Invoice Mailing Address** field to:

-  contacts, where it acts as the default for the documents of that
   customer;
-  customer invoices, where the default can be overridden per document.

Configuration
=============

1. Go to *Contacts*, open a customer and set **Invoice Mailing Address**
   under the *Invoicing* tab, *Customer Invoices* group.
2. Any contact can be selected, including a contact that does not belong
   to the customer (e.g. an accounting firm). The field is only used to
   print the recipient address.
3. Leave the field empty to address the document to the billing partner,
   which is the standard behavior.

The value set on a contact is also used by its child contacts, so it is
normally enough to set it once on the company.

Usage
=====

When an invoice is created, **Invoice Mailing Address** (under the
*Other Info* tab) is filled in from the partner. It can be changed on
the invoice as long as it is not posted, for instance to send a single
invoice to another department.

The mailing address is not propagated back from the partner to the
invoices already created: changing the default on a contact only affects
new documents.

The recipient address block of the invoice report shows the mailing
address when one is set, and the billing partner otherwise. The customer
tax ID is always printed for the billing partner.
