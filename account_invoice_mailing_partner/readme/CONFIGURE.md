1.  Go to *Contacts*, open a customer and set **Invoice Mailing Address** under
    the *Invoicing* tab, *Customer Invoices* group.
2.  Any contact can be selected, including a contact that does not belong to the
    customer (e.g. an accounting firm). The field is only used to print the
    recipient address.
3.  Leave the field empty to address the document to the billing partner, which
    is the standard behavior.

The value set on a contact is also used by its child contacts, so it is normally
enough to set it once on the company.
